# NOEMA · Infinite Canvas Mosaic

独立开发的沉浸式海报墙静态演示，参考 [Folia Major 的 PosterWall](https://github.com/chthollyphile/folia-major/blob/main/src/components/app/lattice/PosterWall.tsx) 的视觉方向，而非复制其源代码。

## 运行

解压整个 ZIP，保留 `index.html` 与 `assets/` 的相对目录。在现代浏览器打开 `index.html` 即可使用，无需依赖、构建或后端服务器。也可在目录运行 `python -m http.server 8000` 以本地服务器方式预览。

## 功能

- 12 × 8 固定几何模板平铺，并在二维方向无限重复；约 6 世界像素的直角缝隙。
- 原生 Pointer Events：鼠标拖动、触摸拖动、双指捏合、滚轮绕指针锚点缩放；支持放大、缩小、重置快捷按钮。
- 视口裁剪与超扫：只创建视口附近磁贴，最多 220 个实例；`IntersectionObserver` 延迟发起缩略图资源请求。
- 缩略图与原图分离：未展开时请求 `thumb-NN.webp`，展开时才请求 `poster-NN.webp`，新资源解码完成后渐显，避免全黑闪屏。
- 原位扩展与阻尼弹簧：邻近磁贴根据选中作品的目标包围盒计算位移，图像矩形与镜头的状态可随时打断并重定向。
- 背景磁贴暗化、固定悬浮圆形控件、无圆角无粗边框、中文辅助说明和响应式控制布局。
- 键盘：`Tab` 遍历可见磁贴，`Enter`/`Space` 展开，`Esc` 收起，方向键平移，`+`/`-` 缩放，`0` 重置，`?` 操作说明。
- 支持 `prefers-reduced-motion`，在减少动态效果偏好下直接切换到目标状态。

## 交互与体验优化（2026-11-08）

- 画布相机按需进行视口裁剪，减少平移与动画时的重复 DOM 遍历；静止磁贴不再每帧写入位置和尺寸。
- 图片在加载事件后尝试 `decode()` 再显现，避免展开时的突然闪屏。
- 展开作品提供 `aria-expanded` 状态与屏幕阅读器实时提示；非视口磁贴从 Tab 顺序排除。
- 操作说明弹窗开启时锁定背景焦点，并在关闭后恢复此前的焦点。
- 支持 `R` 或右下角罗盘按钮随机发现当前画布内的作品。
- 移动端按钮恢复 44px 触控尺寸，并消除底栏文案遮挡。
- 增加使用 Node 内置测试运行器的资源与模板检查。

运行检查：`node --test tests/static.test.mjs`（Node.js 18 或更新版本）；启动与展示仍然零依赖。

## 替换图片

修改 `index.html` 里的 `artworks` 列表和 `photo(id, width)` 函数。正式项目可将缩略图替换为 CDN 自动生成的 WebP/AVIF 小图，将原图映射为独立原始尺寸 URL；推荐响应式 `srcset`、合理 HTTP `Cache-Control` 和单独的图片缓存策略。

本示例图片由生成式图像工具创作，主要用来展示布局与交互，不是 Folia Major 的媒体资产。

## 当前范围

这是没有服务端的 UI 演示，不包含图片管理、搜索、账户或持久化自定义收藏。图片加载使用浏览器原生缓存，不包含 Service Worker 离线缓存。扩展重排是针对视觉效果的局部推挤，并不是约束求解器级别的全局零重叠排布。

## 2026-11-08 · 本地图片库（第三轮）

NOEMA 现在可直接浏览电脑上的图片，无需上传到服务器或配置后端：

1. 点击右上角 **文件夹** 按钮，选择整个本地文件夹（浏览器支持 `webkitdirectory` 时可递归导入子目录）。
2. 点击右上角 **图片** 按钮，可以多选单独的图片文件；也可以直接把文件或文件夹拖放到页面。
3. NOEMA 会按自然文件名排序（`2.jpg` 排在 `10.jpg` 前），在原有 12×8 固定几何模板中展示图片。拖动、触控、滚轮缩放、点击展开和 `R` 随机浏览等交互仍可用。
4. 顶部显示当前图片集合及数量；点击 **DEMO** 返回内置示例图库。

### 隐私与兼容性

- 通过浏览器的 `<input type=file>` / 拖放文件数据读取，图片内容仅保留在当前标签页中，**不会上传到 NOEMA 或第三方服务**。部署的静态网页自身不提供上传接口。
- 选择目录依赖浏览器对 `webkitdirectory` 的支持。文件多选可作为兼容性较好的备选方案；拖放文件夹依赖 `webkitGetAsEntry`，不同浏览器的能力可能不同。
- 通常支持 JPEG、PNG、WebP、AVIF、GIF、BMP 等浏览器可以解码的图片。HEIC/RAW 等格式能否使用取决于浏览器自身的解码能力；本版本不提供额外转码器。
- 单次最多索引 **20,000** 张图（浏览器可能因设备内存与文件数量提前遇到性能限制）。同一文件夹的图片不会在刷新页面后自动恢复，需重新选择。
- 使用固定几何模板周期性填充画布，**可见画面会重复部分图片**。当前不是“不重复遍历所有文件”的全局布局算法，也不提供磁盘索引或后台文件监视。

### 图片加载和内存管理

- 只对出现在视口附近的图片按需制作缩略图；并发解码上限为 **3**。
- 缩略图最长边约 **500px**，WebP 压缩质量 0.78；并保留横竖图比例。浏览器使用 `createImageBitmap` / Canvas 生成缩略图，不提前加载目录内全部原图。
- 缩略图 Blob URL 缓存最多保留约 **260** 项（可见、仍被引用的项暂不回收）；切换图库后撤销旧 URL。
- 只有展开磁贴时才创建指向原图文件的 Blob URL，关闭或切换图片会撤销 URL，减少大文件长期占用。
- 解码失败的文件会尝试用浏览器原生 `<img>` 显示，仍失败则保留渐变占位图，不中断画布。
