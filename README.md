# NOEMA · Infinite Canvas Mosaic

独立开发的沉浸式海报墙静态演示，参考 [Folia Major 的 PosterWall](https://github.com/chthollyphile/folia-major/blob/main/src/components/app/lattice/PosterWall.tsx) 的视觉方向，而非复制其源代码。

## 运行

解压整个 ZIP，保留 `index.html` 与 `assets/` 的相对目录。在现代浏览器打开 `index.html` 即可使用，无需依赖、构建或后端服务器。也可在目录运行 `python -m http.server 8000` 以本地服务器方式预览。

## 功能

- 12 × 8 固定几何模板平铺，含纵向与横向矩形；约 6 世界像素的直角缝隙。示例模式无限重复，本地模式中的每张图片只出现一次。
- 原生 Pointer Events：鼠标拖动、触摸拖动、双指捏合、滚轮绕指针锚点缩放；支持放大、缩小、重置快捷按钮。
- 视口裁剪与超扫：只创建视口附近磁贴，最多 220 个实例；`IntersectionObserver` 延迟发起缩略图资源请求。
- 缩略图与原图分离：未展开时请求 `thumb-NN.webp`，展开时才请求 `poster-NN.webp`，新资源解码完成后渐显，避免全黑闪屏。
- 原位扩展与阻尼弹簧：邻近磁贴根据选中作品的目标包围盒计算位移，图像矩形与镜头的状态可随时打断并重定向。
- 背景磁贴暗化、固定悬浮圆形控件、无圆角无粗边框、中文辅助说明和响应式控制布局。
- 键盘：`Tab` 遍历可见磁贴，`Enter`/`Space` 展开，`Esc` 收起，方向键平移，`+`/`-` 缩放，`0` 重置，`?` 操作说明。
- 支持 `prefers-reduced-motion`，在减少动态效果偏好下直接切换到目标状态。

## 交互与体验优化（2026-11-08）

- 画布相机按需进行视口裁剪，减少平移与动画时的重复 DOM 遍历；静止磁贴不再每帧写入位置和尺寸。
- 图片在加载事件后尝试 `decode()` 再显现，避免展开时的突然闪屏。
- 展开作品提供 `aria-expanded` 状态与屏幕阅读器实时提示；非视口磁贴从 Tab 顺序排除。
- 操作说明弹窗开启时锁定背景焦点，并在关闭后恢复此前的焦点。
- 支持 `R` 或右下角罗盘按钮随机发现当前画布内的作品。
- 移动端按钮恢复 44px 触控尺寸，并消除底栏文案遮挡。
- 增加使用 Node 内置测试运行器的资源与模板检查。

运行检查：`node --test tests/*.test.mjs`（Node.js 18 或更新版本）；启动与展示仍然零依赖。

## 2026-11-08 · 本地图片库（第三轮）

NOEMA 现在可直接浏览电脑上的图片，无需上传到服务器或配置后端：

1. 点击右上角 **文件夹** 按钮，选择整个本地文件夹（浏览器支持 `webkitdirectory` 时可递归导入子目录）。
2. 点击右上角 **图片** 按钮，可以多选单独的图片文件；也可以直接把文件或文件夹拖放到页面。
3. NOEMA 会按自然文件名排序（`2.jpg` 排在 `10.jpg` 前），在 12×8 固定几何模板中展示图片，并按可识别的纵横比为竖图优先匹配纵向插槽。拖动、触控、滚轮缩放、点击展开和 `R` 随机浏览等交互仍可用。
4. 顶部显示当前图片集合及数量；点击 **DEMO** 返回内置示例图库。

### 隐私与兼容性

- 通过浏览器的 `<input type=file>` / 拖放文件数据读取，图片内容仅保留在当前标签页中，**不会上传到 NOEMA 或第三方服务**。部署的静态网页自身不提供上传接口。
- 选择目录依赖浏览器对 `webkitdirectory` 的支持。文件多选可作为兼容性较好的备选方案；拖放文件夹依赖 `webkitGetAsEntry`，不同浏览器的能力可能不同。
- 通常支持 JPEG、PNG、WebP、AVIF、GIF、BMP 等浏览器可以解码的图片。HEIC/RAW 等格式能否使用取决于浏览器自身的解码能力；本版本不提供额外转码器。
- 单次最多索引 **20,000** 张图（浏览器可能因设备内存与文件数量提前遇到性能限制）。同一文件夹的图片不会在刷新页面后自动恢复，需重新选择。
- **本地图库不再周期性重复图片**。每个文件分配唯一的局部空间位置；示例图库保留无限重复以便探索。当前仍不提供磁盘索引或后台文件监视。

### 图片加载和内存管理

- 只对出现在视口附近的图片按需制作缩略图；并发解码上限为 **3**。
- 缩略图最长边约 **500px**，WebP 压缩质量 0.78；并保留横竖图比例。浏览器使用 `createImageBitmap` / Canvas 生成缩略图，不提前加载目录内全部原图。
- 缩略图 Blob URL 缓存最多保留约 **260** 项（可见、仍被引用的项暂不回收）；切换图库后撤销旧 URL。
- 只有展开磁贴时才创建指向原图文件的 Blob URL，关闭或切换图片会撤销 URL，减少大文件长期占用。
- 解码失败的文件会尝试用浏览器原生 `<img>` 显示，仍失败则保留渐变占位图，不中断画布。

## 第四阶段 · 唯一图像空间、竖版布局与完整原图查看器

### 双模式空间布局

- **示例模式（Demo）**：保留可沿二维无限平移的周期海报墙。
- **本地模式（Local）**：将导入的图片按 9 个槽位为一组分配到有限的矩形块中；每张图片只有一个稳定 ID 与唯一位置，不再取模重复展示。画布仍然可以自由平移、缩放，但空间之外不凭空复制图片。
- 12×8 基础模板含横向、方形和竖向磁贴，保持直角与约 6px 世界坐标间隙。浏览器优先读取 JPEG、PNG、WebP、GIF、BMP 文件头中的尺寸，以便同一组内竖图优先进入竖向插槽。首批约 90 张同步完成轻量尺寸预检，其余在后台逐批扫描；无法识别尺寸的 AVIF 等文件会采用保守回退，尚未考虑所有格式的 EXIF 旋转情况。
- 单张纵向图片自动选用竖向插槽并居中呈现。导入顺序仍根据自然文件名排序，但**组内的视觉显示顺序**可能因纵横比匹配而调整。

### 两级查看体验

1. **Focus（原位展开）**：点击磁贴放大，周围磁贴按单调空间坐标映射整体退让，避免重新排列后的矩形相撞。连续的弹簧位移动画仍可被中途打断或更改目标。
2. **Inspect（完整原图）**：选中作品后点击右上角“完整查看原图”按钮，或按 `I` 打开；原图使用 `contain` 效果所需的完整比例，不做封面裁切。支持拖动、滚轮缩放、触控双指缩放、适应屏幕（`0`）、100% CSS 像素查看（`1`）、前后切换（`←`/`→`）、Esc 返回。`100%` 指原图的 1 像素对应 1 个 CSS 像素，可能与高 DPR 显示器的物理像素不同。

### 设计与隐私

- 本地图册中，磁贴标题默认隐去，Hover/键盘聚焦时才显示，减少文字遮挡摄影内容。
- 文件不上传服务器，原图查看只创建当前图片的对象 URL，关闭/切换时释放。仅接受预期的常见栅格图类型；不将 SVG 作为本地图像导入格式。
- `prefers-reduced-motion`、键盘焦点、对话框 Tab 约束等行为继续保留。

## 2026-11-08 · v5 大图库稳定性升级

### 缩略图后台处理

- 新增独立的 `thumbnail-worker.js`。在支持 `Worker` + `OffscreenCanvas` 的安全网页环境中，将图片解码、缩放和 WebP 编码移到 Worker，避免这一过程占用画布交互主线程。
- Worker 处理失败会自动回退到原来的 Canvas 流程；直接通过 `file://` 打开时也采用回退，不要求用户运行本地服务器。
- 保持 3 个以内缩略图并发请求以及按视口加载。图片按最长边约 500px 生成，保留纵横比。
- 缓存同时使用 **260 项数量限制**和**32 MiB 压缩 Blob 大小预算**，优先回收不可见图片。当前可见磁贴是固定保留项，因此这不是包括像素解码、GPU 纹理与文件对象在内的严格内存上限。

### 目录导入、进度与取消

- 在支持 File System Access API 的浏览器和安全上下文中，使用系统目录选择器，增量读取文件；不支持时自动保留原本的 `<input webkitdirectory>` 方式。
- 目录遍历与首次图片比例探测期间显示轻量进度条，可点击 **取消**。在导入正式生效前取消不会替换已有图库。
- 新增「最近文件夹」按钮：支持的浏览器在首次授权后，可把目录句柄保存到站点的 IndexedDB；**仅保存句柄，不保存图片原始文件**。用户再次点击后，才检查权限并重新扫描目录。刷新页面不会自动读取文件。
- 可在操作指南中使用 **清除记住的文件夹** 删除该保存记录。浏览器可能要求重新授予权限；目录选择器、拖放文件和多选图片仍保持可用。
- 从目录读取时保留子文件夹相对路径作为详情描述。

### 兼容性及限制

- File System Access API 和 Worker/OffscreenCanvas 的可用性取决于浏览器与页面安全上下文；**不承诺所有浏览器均能保存、恢复最近文件夹**。
- 本版本没有把全部本地图片写入 IndexedDB，也未实现可跨会话持久化的缩略图文件缓存。重新打开目录会重新枚举文件，并按需生成缩略图。
- 目前缓存预算计算的是压缩缩略图 Blob 大小，不包含浏览器内部解码缓存和 GPU 内存；尚未完成 20,000 张真实高分辨率照片的端到端压力测试。
- 当前所有文件内容仅在浏览器本地处理，应用不提供上传接口，代码不包含上传图片的网络请求。

## v6 · 缩略图跨会话复用与缓存管理（2026-11-08）

- 新增原生 IndexedDB 本地缩略图存储 `thumbnail-store.js`，与 v5 已有的目录句柄数据库隔离。**不保存原图内容**；仅缓存用户已实际浏览、成功转换的 WebP 缩略图。
- 文件再次选中或重新授权同一目录时，浏览到相同图片优先读取缓存，避免重复 WebP 解码和生成。缓存键由相对路径、文件大小、修改时间及文件首尾少量字节的摘要构成（数据库中不保留明文文件名），属于快速失效判定而非整个文件内容的校验。
- 持久缓存默认最多 **1200 项 / 96 MiB 压缩图片数据**，按最近使用时间清理旧条目；内存中依旧独立采用 **260 项 / 32 MiB** 预算。IndexedDB 额度由浏览器管理，私密窗口、`file://` 或禁用存储时可能不持久化；系统回收缓存不会影响原始文件。
- 通过右上角帮助面板查看本地缓存项数、数据大小、本次会话命中次数，也可以点击 **清除缩略图缓存**。该操作只删除本站生成的缩略图，不删除电脑上的照片，也不撤销已保存的目录权限；「清除记住的文件夹」仍是独立操作。
- 提供静态与模拟数据库测试；浏览器若拒绝持久化存储，自动使用现有 Worker / 主线程缩略图路径，页面仍能正常浏览。

> 限制：持久缓存提高重复打开时的缩略图加载效率，不保存图库完整索引或原始图像，也不能跨浏览器共享。浏览器可能随时清理网站存储。此版本未完成 20,000 张真实高分辨率照片的端到端压测。

## 2026-11-08 · v7：图片搜索和布局索引

### 快速搜索

- 点击画布右下角的**搜索**按钮，或按 `/`、`Ctrl+K`、`⌘K` 打开临时搜索面板。
- 支持匹配当前图库的文件名、相对路径和分类；对中文进行 NFKC 规范化和大小写不敏感匹配。
- 使用 `↑` / `↓` 浏览、`Enter` 定位，`Esc` 退出；鼠标或触摸也可选择结果。
- 搜索结果最多渲染 **40** 项，显示实际匹配总数，避免向 DOM 一次性插入海量条目。
- 选择结果时相机会移动到作品所在的空间位置并将其展开；**本地图库不会生成重复图片**。
- 文件名只在当前标签页内用于搜索，不会被上传或发送给第三方服务。搜索并不提供离线目录读取权限。

### 图片比例持久索引

- 新增 `library-index.js`：通过 IndexedDB 记录图片比例和元数据指纹。下次**由用户重新选择或授权打开同一图库**时，优先复用未更改文件的比例结果，从而减少重复读取图片头部。
- 指纹由目录标签、相对路径、文件大小、修改时间和 MIME 类型计算，只保存不含明文路径的摘要、比例与使用时间；**不保存原图、缩略图、可直接访问文件的路径或目录读取权限**。摘要不等于数据加密或身份匿名化。
- 在操作指南中可查看索引项目数与当前页面的命中次数，或点击「清除布局索引」。索引与已有的 WebP 缩略图缓存是**两个独立存储区**，清除一个不会删除另一个，也不会删除用户原图。
- 索引默认最多约 40,000 项，超额时按记录时间淘汰至约 32,000 项；若 IndexedDB 不可用，则退回原先按需读取比例的方式。
- 元数据更改会产生新的索引键，旧记录可在超额淘汰或手动清理时删除。**如果文件内容改变，但路径、大小和修改时间都不变，索引无法可靠识别**，此时可手动清理索引。

### 目前仍未实现

浏览器每次重新打开文件夹仍需枚举文件并获取 `File` 对象（仅比例计算可以命中索引）；不提供实时文件系统监控、在未授权时访问本地目录、完整图片内容指纹或原始文件的持久缓存。大图片库的完整端到端性能测试还未完成；20,000 张测试属于布局映射/搜索的逻辑测试，而非真实大目录压力测试。

## v8 · 模块化、搜索筛选、目录扫描与性能观测（2026-11-08）

### 架构调整

保持零构建、原生 HTML/JS 的发布方式，将部分可纯函数化的逻辑从主页面拆出：

- `src/canvas-core.js`：按指针锚点缩放、世界视口计算、可见磁贴优先排序。优先保留真实视口内的图片，再考虑 Overscan 区域。
- `src/search-core.js`：统一名称/路径/分类的 Unicode NFKC 匹配、支持空格分隔的多关键词，扫描全部结果后保留排名最高的 40 项，避免后部精确命中被前 40 条覆盖。
- `src/directory-scanner.js`：分批枚举、过滤非图片扩展名、最多 4 个并发文件读取、阶段性向界面报告扫描进度；取消后不会替换当前图库。
- `src/performance-monitor.js`：独立、按需启动的帧间隔采样器；关闭时停止采样和动画帧请求。

各模块在 `<script>` 标签下按顺序加载，不依赖打包器；复杂的相机交互、原图查看器和图片缓存暂时继续由 `index.html` 协调。**这是渐进式模块化，并非已经完成整个系统的 TypeScript 重构。**

### 可用功能

- 本地图库的搜索面板输入关键词后，可点击「**仅显示匹配项**」，将画布暂时重排为唯一、连续的命中图片集合；顶部显示筛选词与当前/总图片数，点击「清除」返回完整图库。
- 搜索面板始终针对完整本地图册检索，选择一个不在当前筛选子集中的结果会先恢复图库再定位。示例模式仍保留无限拼贴，但不启用筛选重排。
- 目录扫描仅读取授权文件，进度显示枚举项目数、图片数、目录数与耗时；选中非图片文件会跳过。采用逐批让出主线程的方式，减少大目录扫描期间的输入迟滞。
- 按 **Shift+P** 或在帮助面板点击「显示性能指标」，显示每秒采样的 FPS 估计、最慢帧、当前磁贴数、裁剪候选数、缓存体积、并发任务与待处理队列；关闭即停止。FPS 是页面当前的近似采样值，不是长时性能证明。

### 测试与诊断

```bash
node --test tests/*.test.mjs
node scripts/benchmark.mjs
```

测试包含画布缩放锚点、搜索排名、筛选可逆状态、目录扫描并发及取消、性能采样状态等。`benchmark.mjs` 是 **CPU 微基准**，不能替代在 Chromium 中用 10,000 或 20,000 张真实图片测量首屏、内存、交互延迟与长时间浏览。

**已知限制：** 目前仍需要用户手动重新授权或选择目录；索引并非实时文件系统监控；筛选切换会清理当前内存缩略图 URL，但可命中 v6 的 IndexedDB 持久 WebP 缓存。HTML 主文件仍偏大，后续适合逐步抽离 Inspector、Gallery Controller 和可访问性对话框。
